This is a Comic Book Management System that the user can manage a comic book store online using a database
this application is easier to manage thanks to a simple User Interface(UI) that us connect to the database using JDBC and DAO 
that helps connect to the program by using CRUD operation (Create, Read, Update, Delete). It also has a search function and a multilingual support. 

Features:
Multi-Language:
English
French
Spanish

Comic Management:
Create new comics
Update comic
Delete comic
Search comic by ID, Name, Issue and Publisher
View of the data

Customer Management:
Create new customer
Update customer
Delete customer
Search customer by ID, Name, Email and PhoneNumber
View of the data

Employee Management:
Create new Employee
Update employee
Delete employee
Search employee by ID, Name
View of the data

Order Management:
Create new order
Update order
Delete order
Search order by ID, order Date, customer ID and comic ID
View of the data
